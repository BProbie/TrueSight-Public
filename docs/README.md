## 这个项目是什么

一句话：**一套面向品牌与机构的仿冒检测防护系统**，覆盖仿冒站点发现、判定、取证与处置。
三条入口（外链拦截 / 周期扫描 / 人工举报）把线索送进同一套检测引擎，
经域名、内容、证书、备案与可选的 AI 灰区复核给出可解释的风险结论，
再由取证、研判报告、举报留痕与脱敏态势完成闭环。

三个关键词决定了它的所有设计：

* **多入口、一套引擎** —— 外链拦截是最低延迟的旁路入口（不改站点源码、可随时摘除）；
  周期扫描负责主动发现，人工举报承接外部线索。三者共用同一评估器、评分与处置链；
* **分级降级** —— 任何一项能力不可用（网络失败、模型没配、情报源缺失）都不阻断判定，
  只记一条人可读的降级说明，结论照给；
* **隐私最小化** —— 公网侧只拿脱敏投影，举报人 IP 只存带盐哈希，密钥只可写入不可读回。

项目不绑定单一行业：受保护资产、品牌词与行业词都由部署方配置；默认检测策略与
新域监控词表覆盖多个常见高价值行业，同时保留按客户场景收窄的空间。

## 文档写作约定

* 所有文档与代码注释使用中文；术语首次出现时给出英文原词（便于检索官方资料）；
* 每个「设计决定」都写清**为什么**，不只写「是什么」——因为答辩与交接时被问的都是为什么；
* 明确区分「**已实现**」与「**明确降级/未实现**」：后者不是缺陷隐瞒，而是方案里的分级策略
  （见 [FAQ](FAQ.md#六哪些是明确降级而不是没做)）。
